HALCYON FERRIS -- DVORAK LAYOUT (nils)

Notation:  x/y   = dual function: tap x, hold y
           *Mod  = one-shot modifier (double-tap to lock)
           TO(n) = switch to layer n
           [S]   = shifted output shown below each layer

  Shift + tap-dance hold:  ,/- → _    ./ ! → !    :/; → :

Home row mods (one-shot, double-tap to lock):
  a = *LAlt   o = *LGui   n = *RGui   s = *LAlt

Umlauts via one-shot RAlt (requires EurKey OS layout):
  Hold ' → release → tap letter:  a = ä   o = ö   u = ü   s = ß
  Uppercase: *Sft → hold ' → release → tap letter:  a = Ä   o = Ö   u = Ü

LAYER 3 -- NAV
==========================================================================

+------+------+------+------+------+   +------+------+------+------+------+
| R Lf | ScLf | MsUp | ScRt | R Rt |   | Back | PTab | NTab | Fwd  | Bksp |
+------+------+------+------+------+   +------+------+------+------+------+
| R Up | MsLf | MsDn | MsRt | Del  |   | Left | Down |  Up  |Right |Enter |
+------+------+------+------+------+   +------+------+------+------+------+
| R Dn | Btn2 | ScUp | ScDn | R Max|   | Btn1 | Home | PgUp | PgDn | BOOT |
+------+------+------+------+------+   +------+------+------+------+------+
                     +------+------+   +------+------+
                     |TO(0) |      |   | RAlt |TO(1) |
                     +------+------+   +------+------+

  No *Sft on this layer (thumb is empty). Shift has no effect on nav/mouse keys.

Mouse: MsUp/Dn/Lf/Rt = pointer, ScUp/Dn/Lf/Rt = scroll wheel
       Btn1 = left click, Btn2 = right click
Browser: PTab = prev tab (Ctrl+Shift+Tab), NTab = next tab (Ctrl+Tab)
Rectangle: R Lf/Rt/Up/Dn = tile left/right/top/bottom (Gui+Shift+arrow)
           R Max = maximize (Gui+Shift+Alt+M)

!! BOOT = enters DFU mode for flashing (bottom-right, layer 3 only)

LAYER NAVIGATION
==========================================================================

Left thumb returns:    (any layer) -> Base
